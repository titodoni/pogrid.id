02 Strategic Vision: The Minimalist Workshop Engine

Product Alignment

Traditional enterprise manufacturing software (SAP, Oracle NetSuite, Odoo Enterprise) fails Indonesian manufacturing SMEs (bengkel bubut, fabrikasi, bengkel las, machining precision) because of overwhelming complexity, high hardware requirements, and expensive consultant implementations.

POgrid Core Product Pillars SME Focus
  • Floor-First Simplicity: Single-touch, 4-digit PIN login (/c/{slug}) optimized for grease-covered hands on cheap Android tablets.
  • Additive Progress Logging: Delta increments (+3 pcs) with immediate visual feedback, not complex multi-step work orders.
  • Sunk-Cost Protection: Non-cancelled WIP items automatically generate sunk-cost accounting entries upon midway termination.
  • Zero-Overhead Office View: Real-time WebSocket board synchronization without refreshing the page.
Why We Reject Enterprise Over-Engineering Anti-Bloat
  • No Microservices Sprawl: A tightly integrated Laravel 11 Modular Monolith gives us instant deploys, zero inter-service network latency, and unified ACID transactions.
  • No Heavy Cloud Lock-In: Runs effortlessly on a single Hostinger server with Neon Postgres, costing ~$20-30/month total.
  • No Enterprise Message Queues (Kafka/RabbitMQ): Lean database-backed queues processed via 1-minute cron schedules.
  • Zero Redux/Zustand Complexity: React 18 + Inertia v2 server-driven state keeps client bundles tiny and responsive.

05 Codebase Architecture & Hotspot Decomposition

Modular Monolith

To ensure high developer velocity without introducing microservice orchestration nightmares, POgrid adheres strictly to the Modular Monolith Pattern (ADR-001). The business logic is strictly owned by the server (ADR-002), with fail-closed tenant scoping (ADR-003) and clear service boundaries (ADR-005).

Backend Hotspot Remediation -580 LOC Reduced
Controllers are now thin HTTP orchestrators. Logic was cleanly moved into dedicated services:
  • StageTemplateService — Custom stage creation & templates
  • UserManagementService — Tenant staff & PIN lifecycle
  • ReportingService — Aggregations, delay analyses & KPIs
  • TenantSettingsService — Workshop profile & billing state
  • WorkerReportingService — Floor queries & trouble logs
  • ExportService — PDF, Excel, and CSV multi-format exports
Frontend Feature Extraction Modular UI
Massive pages in resources/js/Pages/ decomposed into self-contained feature units:
  • features/worker/ProgressControls.tsx — Additive stepper logic
  • features/worker/QcReworkForm.tsx — NG / OK action handling
  • features/worker/FinancePanel.tsx — Invoice & payment view
  • features/worker/KendalaForm.tsx — Shop-floor obstacle reporting
  • features/owner/StageTemplateModal.tsx — Workflow setup
  • Hooks/useEchoPresence.ts — Unified WebSocket presence
